### 🕹 [PyKuma](https://github.com/shirkattack/PyKuma)

---

### 🧠 [RADRAG](https://github.com/shirkattack/RADRAG)
A compilation of **Retrieval-Augmented Generation** and Agent scripts — experiments in giving LLMs memory, context, and a sense of purpose.  
**Stack:** Python · LangChain · LlamaIndex · Databricks · OpenAI APIs  
*Goal: make AI recall better than my last combo string.*

---

### 🕷 [SpiderWire](https://github.com/shirkattack/SpiderWire)
A **Scrapy-based news crawler** that collects open-source media articles worldwide for analysis.  
**Stack:** Python · Scrapy · Requests · BeautifulSoup  
*Think of it as a global web-crawling ninja — quiet, efficient, unstoppable.*

---

### 💊 [DrugDetection](https://github.com/shirkattack/drugdetection)
Detecting **drug seizure information** in open-source news using Named Entity Recognition (NER).  
**Stack:** Python · spaCy · Transformers · NLP pipelines  
*Turning unstructured text into actionable intelligence.*

---

**Stack:** Python · DsPy · Streamlit  
*Half spellbook, half lab notebook for LLM tinkering.*
